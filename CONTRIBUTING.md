# Contributing to PatchBatch

Thanks for your interest in contributing to PatchBatch. This project aims to make electrophysiology data analysis easier and less tedious, and contributions from the community will help to expand this goal to more analysis areas.

The easiest way to contribute is through the GitHub Issues page at https://github.com/ck852/patchbatch/issues. If you'd like to contribute code, start by forking the repository and creating a branch for your changes. The codebase follows a service-oriented architecture where UI logic lives in the widgets and dialogs, while analysis logic belongs in the core and services modules. Keeping this separation intact makes the code easier to test and maintain. Before submitting a pull request, run the test suite with `pytest` from the root directory to make sure existing functionality still works. If you're adding new analysis features, consider adding reference file tests that validate output against known-correct reference data. For example, when developing the conductance analysis functionality, I performed the conductance measurements manually in Excel from the raw sweep data to validate that the outputs through the program matched within an acceptable tolerance (1e-6).

For development setup, clone the repository and install dependencies with `pip install -r requirements.txt`. You can run the application directly with `python src/data_analysis_gui/main.py`. The `-debug` flag enables verbose logging if you need to trace through the analysis pipeline.

Questions about the codebase or how to implement a feature are welcome in the Issues section. There's no formal process for proposing changes—just open an issue describing what you have in mind and we can discuss the approach before you invest time in implementation.
